# A number only where it is the point

**Leave out a number the code already says** - how many cases, versions, classes, rows or files. Write "every
Bischoff problem" or "each version", not the count. The code changes, the count does not, and every copy of it
is one more edit.

**Keep a number that is the point:**

- A measured result - a time, a fill, a ratio. In a findings record or a results file the number is the content.
- A number a person decides on - a run time in a recipe ("about 16 hours") tells whoever reads it whether to
  start the run now.

If a number is neither, cut it.

**Why:** on 2026-09-27 adding one version to the benches meant changing case counts in three READMEs, the
recipes and a doc - then changing them all back the next day. Not one of those numbers was the point.
