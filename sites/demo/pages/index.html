Run it yourself

One command starts Binacle.Net on your machine. The Quick Start has the rest.

$ docker run -d --name binacle-net -p 8080:8080 -e SWAGGER_UI=True -e SCALAR_UI=True -e UI_MODULE=True binacle/binacle-net:3
